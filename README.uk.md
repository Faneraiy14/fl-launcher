## Швидкий старт

1. **Завантаж** останній інсталятор зі сторінки [Releases](https://github.com/Faneraiy14/fl-launcher/releases/latest) і встанови (Windows `.exe`; Linux `.AppImage` або `.deb`).
2. **Створи збірку**: зелена кнопка **+ Створити** → *Створити збірку*, обери версію гри й (за бажанням) лоадер. Або встав код від друга через *Імпорт за кодом*.
3. **Натисни «Грати».** Java і файли гри завантажаться самі при першому запуску.

## Завантажити

Останню версію бери на сторінці [Releases](https://github.com/Faneraiy14/fl-launcher/releases/latest) — файл `FL-Launcher-Setup-*.exe`.

Далі лаунчер оновлюється сам: перевіряє релізи при запуску й пропонує встановити нову версію.

> Windows може показати синє вікно «Windows захистила ваш ПК» — у проєкту немає платного сертифіката підпису. Натисни «Докладніше», далі «Виконати все одно».

## Що таке FL Launcher

Лаунчер Minecraft на Electron: керування збірками, автоматичне встановлення
Fabric, Forge, NeoForge та Quilt, пошук і встановлення модів, скіни,
власний мод-лоадер FL Loader. Окрім цього: вбудована оптимізація й
«поремонтувати збірку», знімки з відкатом, пробні копії та коди збірок,
клієнт у грі (HUD, меню, чат) з окремими перемикачами для звичайних
функцій і чітів, косметика з внутрішньою валютою, друзі й чат, історія
якого лежить лише на твоєму комп'ютері.

**Повний список можливостей за блоками: [FEATURES.uk.md](FEATURES.uk.md)**
(той самий текст є всередині лаунчера: кнопка ⓘ внизу лівої панелі → Про лаунчер → Все про FL Launcher).

## Чим відрізняється

Речі, яких у більшості лаунчерів немає в одному місці:

- **Поремонтувати збірку**: читає справжній краш чи лог, пояснює, що зламалось, і виправляє зі скасуванням; нічого не видаляє.
- **Знімки, пробні копії й коди збірок**: пробуй моди безпечно, відкочуйся одним кліком, ділися збіркою коротким кодом.
- **Оптимізація з виміром**: профілі, вибір відеокарти зі вбудованим бенчмарком, моди для FPS лише після твого підтвердження.
- **Власний мод-лоадер (FL Loader)** і клієнт у грі, де звичайні функції й чіти — **окремі перемикачі**, з чіткими попередженнями про бани.
- **Чат із друзями, історія якого лишається на твоєму комп'ютері**, а не на сервері.

## Вимоги

| | |
|---|---|
| **ОС** | Windows 10 / 11 (64-бітна); Linux (64-бітний): `.AppImage` для будь-якого дистрибутива, `.deb` для Debian/Ubuntu-подібних |
| **Minecraft** | від 1.14.4 до найновіших 26.x з FL Loader; для Fabric, Quilt, Forge і NeoForge — версії, які підтримують самі лоадери |
| **Java** | встановлювати не треба: лаунчер сам завантажує потрібну під кожну версію гри |
| **ОЗП** | комфортно від 8 ГБ у системі (сама гра зазвичай отримує 3–6 ГБ залежно від збірки й модів) |
| **Диск** | інсталятор близько 100 МБ; кожна версія гри з бібліотеками займає приблизно 0,5–1 ГБ, плюс твої світи й моди |

> **Що таке «26.x»?** Mojang перейшла на нумерацію за роками: 26.1, 26.2, 26.3 … це релізи Minecraft 2026 року.

## Файли в релізі

- `FL-Launcher-Setup-X.Y.Z.exe` — інсталятор
- `latest.yml` — маніфест для автооновлення, потрібен лаунчеру
- `.blockmap` — дозволяє качати лише змінені частини при оновленні
